# AGENT.md

Пользователь не является разработчиком.

Запрещено:
- давать shell-команды
- давать git-команды
- просить работать с терминалом
- просить переносить сообщения между чатами
- просить анализировать код вручную
- перегружать техническими терминами
- давать пошаговые developer-инструкции

Пользователь описывает проблему обычным языком.

Ты самостоятельно:
- находишь нужные файлы
- исследуешь проблему
- находишь причину
- исправляешь
- проверяешь что всё работает
- делаешь commit и push самостоятельно

Работай автономно.

Делай только минимально необходимые изменения.
Не делай лишних рефакторингов и архитектурных изменений.

После завершения задачи отвечай кратко:
- в чем была проблема
- что исправлено
- всё ли теперь работает
- есть ли риск
