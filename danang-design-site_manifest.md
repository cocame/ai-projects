# ЧЕРТЕЖ САЙТА «ДАНАНГ» (СТАНДАРТЫ 2026)

## 1. СТРУКТУРА СТРАНИЦЫ (ВОРОНКА)
*   **Этаж 1: Главный баннер.** Крупный заголовок «Добро пожаловать в Дананг». Одна кнопка «Выбрать экскурсию» со скроллом вниз. Никакого мелкого текста-мусора под заголовком.
*   **Этаж 2: Продукты (Экскурсии).** Крупный заголовок «Экскурсии из Дананга». В этой плитке находятся ТОЛЬКО экскурсии. Полностью убрать отсюда рестораны и инфо-контент.
*   **Этаж 3: Локальный гид.** Крупный заголовок «Гид по Данангу». Выполняется строго в стиле Bento Grid (монолитная сетка из 3-4 прямоугольных карточек разного размера). Сюда идут рестораны, кофейни и лайфхаки для прогрева.
*   **Этаж 4: Отзывы.** Крупный заголовок «Свежие эмоции». Подзаголовок: "Мы не копируем отзывы на сайт. Посмотрите живые чаты, фотографии и честные мнения наших туристов в реальном времени". Одна центральная кнопка «Читать отзывы в Telegram →» со ссылкой на https://agents.mg (открывать в новой вкладке target="_blank").

## 2. ЖЕСТКИЕ ПРАВИЛА ДИЗАЙНА И КОДА
*   **Ограничение ширины (Boxed Layout как у GetYourGuide)**: Макет не должен бесконечно растягиваться во всю ширину экрана. Задай всему контенту (body/container) максимальное ограничение `max-width: 1440px` и выравнивание строго по центру (`margin: 0 auto`), чтобы при уменьшении масштаба по бокам оставались аккуратные поля, а сетка плиток не ломалась и не уезжала.
*   **Шрифты**: Полный запрет на шрифты с засечками (Serif). Использовать только sans-serif, Inter или system-ui.
*   **Элементы**: Никаких круглых или овальных плашек («вшей») в углах карточек. Любые шильдики (цена, категория) — это строгие прямоугольники со скруглением border-radius: 4px. Выравнивание по левому краю.
*   **Читабельность**: Весь белый текст поверх картинок обязан иметь нижний темный CSS-градиент: background: linear-gradient(to top, rgba(0,0,0,0.85) 0%, rgba(0,0,0,0) 60%).
*   **Цветовая палитра**: Для темных блоков и футера использовать глубокий графитовый цвет (#121212) вместо чисто черного.
*   **Мобильная версия**: На телефонах все сетки (включая Bento Grid) должны перестраиваться в одну удобную вертикальную колонку для скролла пальцем.
